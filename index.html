Build a vocabulary app with MAI¶

Use Flask and browser JavaScript to add speech, voice answers, and memory images to a vocabulary list.

Set up your Codespace, then follow the steps below. Work in starter/; compare with solution/. After each working feature, try one of its experiments.

See the app in action

Silent walkthrough with example model responses. Plays once; close this panel to hide it.

Step What you build
00 — Open the app A page served by Flask.
01 — Word list Word pairs saved in the browser.
02 — Speech English and target-language playback.
03 — Transcription Recording, WAV conversion, and recognized text.
04 — Matching Feedback on the spoken answer.
05 — Images A generated visual cue for each word.
