What the prices establish¶

Public Azure USD pay-as-you-go rates, checked 18 September 2026. These are normalized inference budgets, not measured app runs or a claim of equal quality. Cache savings, free allowances, negotiated rates, and Batch/Flex discounts are excluded.

Transcription: the MAI announcement quotes $0.10/hour; Speech pricing marks a discount through 31 December 2026, while its generic MAI table still shows $0.36/hour. Images: text-to-image only, with no input image or web grounding. Try a controlled comparison¶

Use the app and the comparator's existing playground—no new adapter needed.

  1. Pick one feature and ten pairs in a language supported by both models. Reuse the same WAV for transcription, text/language for speech, or prompt and requested size for images.
  2. Run each model three times. Record useful results, errors, total latency, and its actual billable units. For text, include reasoning tokens.
  3. Compare cost per useful result, not just price per request. Keep voice, quality, deployment, region, and settings in your notes.

Storage and answer matching make no model call. Gateway, hosting, and Codespaces costs are separate.
